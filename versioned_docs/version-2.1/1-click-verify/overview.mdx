## About 1-Click Verify

**1-Click Verify is the _best_ way to capture a user's real phone number.** It works by waterfalling across three channels:
1. **Autofill:** We autofill the user's _verified_ phone number (with no user input!).
2. **Silent:** We silently verify a phone number the user inputted (with no user SMS!).
3. **SMS:** We verify a phone number the user inputted by sending them an SMS with a verification code and/or link.

See [coverage](#coverage) for details on how often each of these channels succeeds.

Collecting a user's verified phone number is necessary to use our flagship [1-Click Signup](/1-click-signup) product, so 1-Click Verify provides a powerful and easy to integrate solution.

## Phone Carrier Compliance

Autofilling verified phone numbers and sending SMS in the US requires onerous compliance reviews by phone carriers. We handle all of this complexity, so you don't have to.


## Benefits

- **Magically autofill verified user phone numbers:** After years of effort, we've implemented a way to autofill verified phone numbers _with no user input!_ This is the best user experience on the planet. Painless, frictionless phone verification.
- **Easily verify user phone numbers:** 1-Click Verify makes it extremely easy to verify user phone numbers, with minimal integration work.
- **Seamlessly integrate with 1-Click Signup and 1-Click Health:** Phone verification is the prerequisite for using our flagship [1-Click Signup](/1-click-signup) product, so 1-Click Verify can smoothly flow into 1-Click Signup (which can then flow into 1-Click Health).


## Coverage

1-Click Verify works for ~100% of US adults (264M people): anyone with a cell phone! That said, coverage varies across the three channels and depends on some details of your use case and implementation. Use the calculator below to estimate coverage.

:::tip
Even if the autofill or silent channels only work for a small percentage of your users, they can _substantially_ boost overall conversion (and user delight!) in your onboarding flow, so we highly recommend them.
:::

:::important
**We currently only cover people in the United States,** but we're soon adding new geographies. If there are particular geographies that would be most helpful for your use case, please let us know by emailing Support@Verified.inc, and we'll prioritize accordingly.
:::

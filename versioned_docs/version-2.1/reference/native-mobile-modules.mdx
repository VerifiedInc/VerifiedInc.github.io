## `VerifiedCellular`

The `VerifiedCellular` module allows you to easily choose a cellular connection over a WiFi one from within a native mobile app, which dramatically bosts coverage for the [1-Click Verify](/1-click/verify) autofill and silent channels.


### Usage

To use the module:
1. Copy the code from the [GitHub repository](https://github.com/VerifiedInc/verified-cellular) (MIT licensed). 
2. Follow the 1-Click Verify [API Integration](/1-click-verify/guides/api-integration) guide.


### Platform Support

There are currently versions for the following platforms:
- Android (Kotlin)
- iOS (Swift)
- Flutter
- React Native

:::tip Let Us Know if You Need Other Platforms!
If you use another platform for native mobile development, let us know and we'll add support for it!
:::
